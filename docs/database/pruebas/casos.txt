# Casos de la Fase 0 para verificar-fase0.sh. Una línea por caso: ESPERADO ||| SQL
#   · ESPERADO = OK: la sentencia debe funcionar.
#   · ESPERADO = otra cosa: la sentencia debe FALLAR y el mensaje de error debe contener ese texto (el nombre del CHECK o de
#     la restricción que la rechaza, o parte del mensaje).
# Cada caso corre dentro de una transacción que se deshace (ROLLBACK): no deja datos. Los marcadores {U} (estudiante de
# prueba), {A} (admin de prueba), {L} (lugar «Biblioteca Central»), {E} (un evento [Prueba]), {C} (una comunidad) y {R} (un
# reporte PENDIENTE) se reemplazan por subconsultas. Para comprobar un resultado se usa un SELECT que falla si no se cumple:
# SELECT IF(condición, 1, (SELECT 1 UNION ALL SELECT 2)).
